## 可以做什么

- **查资料**：搜索电影、剧集与影人，浏览简介、海报和演职员，探索电影节与获奖合集。
- **看评分**：参考豆瓣、IMDb、烂番茄、Letterboxd、TMDB、Trakt 的可用评分，支持分季与 IMDb 逐集评分。
- **记观影**：整理想看和看过，记录个人评分、日期、短评及重看，建立自己的片单。
- **做回顾**：查看观影日历和统计，生成年度观影年册，保存或分享海报。

## 使用与更新

下载 APK 后按系统提示安装。已有版本可在「个人 → 设置 → 版本更新」中升级。

观影记录保存在本机，无需注册余影账号；可在「设置 → 备份与恢复」中导出或导入。更新时直接覆盖安装，请勿先卸载。

<details>
<summary>豆瓣评分怎么设置？</summary>

打开「个人 → 设置 → 豆瓣 Cookie」，可通过豆瓣官网网页登录自动获取，也可手动填写。Cookie 加密保存在本机，查询时经 HTTPS 传给网关，仅用于获取豆瓣评分和条目信息。不设置也可使用其他功能。

</details>

<details>
<summary>为什么有的作品缺分或加载失败？</summary>

各平台的收录和评分范围不同，网络或第三方服务限制也可能影响加载。可稍后重试或切换网络；GitHub 下载慢时，使用上方「下载余影」入口。

</details>
